# MULTIPHYSICS-ANALYSIS-OF-A-REPRESENTATIVE-SMALL-TURBOPUMP-FED-LIQUID-C-D-ROCKET-NOZZLE
2D-axisymmetric, transient, pressure-based CFD analysis (ANSYS Fluent) using k-w SST turbulence model  and coupled thermal-structural FEA (Inconel 718) of a 30-bar LOX/RP-1 C-D rocket nozzle. Validated against RPA performance data.
